# LABO-Premieres-Nations

Depot d'essai prive pour apprendre GitHub et la structure d'un site.

## Arborescence

- `index.html` : page d'accueil du labo
- `articles/` : pages d'articles de test
- `assets/css/` : styles CSS
- `assets/js/` : scripts JS
- `locales/` : exemples FR/EN/ES
- `docs/` : notes de pratique

## Utilisation locale

1. Ouvrir un terminal dans ce dossier
2. Lancer: `python -m http.server 8081`
3. Aller sur: `http://localhost:8081`
