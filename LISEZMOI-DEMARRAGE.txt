╔══════════════════════════════════════════════════════════════╗
║  LABO PREMIÈRES NATIONS — MODE D'EMPLOI (sans terminal)     ║
╚══════════════════════════════════════════════════════════════╝

Tu n'as PAS besoin d'ouvrir PowerShell, CMD ou un terminal.
Double-clic sur un fichier .bat = Windows ouvre une fenêtre noire
toute seule. C'est normal. C'est le "serveur".


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ÉTAPE A — Avoir le dossier LABO sur ton PC (pas seulement GitHub)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

GitHub (site web) = tu VOIS le code en ligne.
Ton PC (dossier local) = tu VOIS le site dans Chrome.

Si tu n'as que GitHub dans le navigateur, le LABO n'est pas encore
sur ton PC. Deux options :

  OPTION 1 — Télécharger (le plus simple)
  ----------------------------------------
  1. Va sur : https://github.com/socrate83/LABO-Premieres-Nations
  2. Bouton vert "Code" → "Download ZIP"
  3. Dézippe le ZIP (clic droit → Extraire tout)
  4. Tu obtiens un dossier : LABO-Premieres-Nations
  5. Mets-le où tu veux, par exemple :
     C:\Users\socra\LABO-Premieres-Nations

  OPTION 2 — Déjà cloné avec Git
  ------------------------------
  Le dossier existe quelque part sur ton disque.
  Cherche "LABO-Premieres-Nations" dans la barre de recherche Windows.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ÉTAPE B — Vérifier que les bons fichiers sont là
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Ouvre le dossier avec l'Explorateur Windows (icône dossier jaune).
Tu DOIS voir ces fichiers à la racine :

  LABO.bat              ← le principal (double-clic ici)
  DEMARRER-LABO.bat
  serveur.py
  index.html
  LISEZMOI-DEMARRAGE.txt

Si tu ne vois PAS "LABO.bat" :
  → retélécharge le ZIP depuis GitHub (version pas à jour)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ÉTAPE C — Lancer le labo (ZÉRO terminal à ouvrir toi-même)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Double-clic sur :  LABO.bat

  2. Une fenêtre NOIRE apparaît (Windows l'ouvre automatiquement).
     C'est le serveur. NE LA FERME PAS.

  3. Tu dois lire dans cette fenêtre :
       [OK] index.html trouvé
       [OK] Serveur actif — ouvre Chrome : http://127.0.0.1:8081/

     ⚠ NE COPIE PAS ces lignes ailleurs. Lis-les seulement.

  4. Chrome s'ouvre tout seul.
     Sinon, double-clic sur : OUVRIR-CHROME.url
